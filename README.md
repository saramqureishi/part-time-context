# part-time-context

Sara Qureishi's part-time job-search context, CVs and application materials.

## Start here
**Read [`HANDOVER.md`](HANDOVER.md) first** — it explains who Sara is, her rules/preferences, the status of every application, and what to do next. It's written so a new AI assistant (or Sara) can pick up seamlessly.

## Folders
- **`HANDOVER.md`** — full handover document (read this first).
- **`CVs/`** — all tailored CVs as PDFs (Master + one per employer).
- **`documents/`** — EACS application form, cover letters, editable markdown versions.
- **`job-lists/`** — dated lists of job searches by sector/area.
- **`cv-scripts/`** — the Python (reportlab) scripts that generate each CV. Run `python3 make_cv_<name>.py` (use `pip install "reportlab<4.1"`).
- **`part_time_context.docx`** — original context doc from the first sessions.

## Quick facts (see HANDOVER.md for detail)
- Part-time only, **max 20 hours/week** (student visa).
- Not available **Wednesdays or Thursdays** (uni classes).
- Prefers **communication-based** roles; no serving/alcohol/heavy labour.
- CV style: simple English, **no em-dashes**, Pythian-only experience (TEQBIT only on the Cochani CV).
